# Security policy

## Reporting a vulnerability

Please report vulnerabilities in `@fenfill/mcp` privately, either:

- by e-mail to [security@fenfill.com](mailto:security@fenfill.com), or
- through GitHub private vulnerability reporting on this repository ("Security" tab → "Report a
  vulnerability").

Please don't open public issues or pull requests for vulnerabilities.

Include the affected version, what you found and, if you can, steps to reproduce it.

## Scope

This policy covers the `@fenfill/mcp` package and the source in this repository.
